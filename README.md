# Sales Performance Dashboard – Tableau

## 📊 Project Overview

An interactive Sales Performance Dashboard built using Tableau and the Sample Superstore dataset.

The dashboard provides a visual analysis of sales performance across regions, quarters, customer segments, and top-performing products.

## 🎯 Project Objectives

- Analyze overall Sales, Profit, and Orders
- Compare sales performance across regions
- Analyze quarterly sales trends
- Understand sales contribution by customer segment
- Identify top-performing products
- Provide interactive filtering and parameter-based analysis

- Interactive Visualizations

## 📈 Dashboard Features

### KPI Cards
The dashboard displays:
- Total Orders
- Total Sales
- Total Profit

### Region-Wise Sales
Compares sales performance across:
- West
- East
- Central
- South

### Quarter-Wise Sales
Shows sales trends across quarters and years.

### Segment-Wise Sales
Analyzes sales contribution from:
- Consumer
- Corporate
- Home Office

### Top Products
Displays the top N products based on the selected metric.

### Dynamic Parameter

A parameter allows the user to switch the analysis between:

- Sales
- Profit
- Quantity

The Top Products parameter allows the user to dynamically control the number of products displayed.
